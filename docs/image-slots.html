올리는 흐름

  1. 원본 업로드 (JPG · PNG · WEBP). 최소 크기보다 작으면 올리기 전에 알려 줍니다.
  2. 칸 비율대로 데스크탑·모바일 자르기 틀을 겹쳐 보여 주고, 글 안전 영역과 예약 패널이 덮는 자리를 반투명으로 표시합니다.
  3. 사진에서 가장 중요한 지점(초점)을 한 번 누릅니다. 잘리는 방향이 이 점을 기준으로 정해집니다.
  4. 대체 문구(alt)를 적습니다. 비워 두면 저장되지 않게 합니다.
  5. 저장하면 원본은 그대로 두고 1배·2배 WebP를 만들어 씁니다.

저장하는 값

  • 원본 파일 주소, 가로·세로 픽셀
  • 초점 좌표 focal: {x: 0.62, y: 0.40} → 화면에서는 object-position: 62% 40%
  • 필요하면 칸별 수동 자르기 좌표(비율 %)
  • 모바일 전용 사진(히어로), 대체 문구

같이 고려할 점

  • 사진 모음(미디어 라이브러리): 거북이 사진처럼 여러 상품 페이지에 같이 쓰는 사진이 많습니다. 한 번 올리고 여러 칸에서 골라 쓰게 하면 교체가 한 번에 끝납니다.
  • 높이가 글 길이에 따라 변하는 칸(패러·제트, 유의사항, 다른 상품 카드): 비율이 고정되지 않으니 초점을 꼭 받습니다.
  • 고객 후기 사진은 관리자가 올리지 않습니다. 16:10 가운데 자르기로 자동 처리하고, 숨김·삭제만 관리자 화면에 둡니다.
