# 오션스타 Home 리뉴얼 — Claude Design 브리프

> Claude Design 프로젝트에 그대로 붙여넣는 용도. 리포지토리를 못 보는 환경이므로 필요한 값을 전부 포함했다.

---

## 1. 무엇을 만드는가

하와이 와이키키 **거북이 스노클링 투어** 업체 "오션스타"의 고객용 웹사이트 **Home 페이지**를 리뉴얼한다. 실제 운영 중인 예약 사이트이고, 목적은 **투어 예약 전환**이다. 브랜드 인지가 아니라 예약 버튼을 누르게 하는 것이 목표.

- 고객: 하와이 여행 중인 한국인 관광객 (가족·커플·신혼)
- 경쟁 우위: 하와이 한인 최초(2019), 누적 리뷰 14,000+, 자연산 거북이 100% 보장, 51인승 루프탑 보트, 한국인 크루 상주
- 결제까지 사이트에서 끝난다 (Stripe). 현장 결제 없음.

**한국어판과 영어판을 같은 구조로 만든다.** 영어판은 번역본이 아니라 동일 레이아웃·동일 컴포넌트의 쌍둥이다.

## 2. 페이지 구조

Home은 아래 순서로 스크롤된다. 헤더/푸터는 전 페이지 공통.

```
헤더:  로고 | Home  고객후기  FAQ  블로그 | [EN] [내 예약 관리] [투어 예약하기]

1. 히어로            제목 + 부제 + 설명 + 예약 CTA
2. 강점 5가지
3. 추천 프로그램      투어 상품 카드
4. 투어 코스 타임라인  7단계 (픽업 → 하버 → 스노클링 → SUP → 카약 → 보트다이빙 → 드랍오프)
5. 고객후기 발췌      6개 + "전체 후기 보기"
6. 픽업 노선도        접었다 펴는 아코디언
7. FAQ 발췌          6문항 + "전체 FAQ 보기"
8. 하단 CTA 배너

푸터: 영업시간 / 이메일 / 주소 / 인스타 / 유튜브 / 블로그 / 사업자 정보 / 개인정보처리방침 · 이용약관
```

이번 브리프의 시안 범위는 **1·2·3·5번**까지로 충분하다.

## 3. 반드시 지킬 규칙 (기존 사이트 감사에서 나온 것)

지금 사이트를 감사한 결과 나온 문제들이다. 새 디자인은 이걸 반복하면 안 된다.

1. **굵기로 위계를 만들지 말 것.** 현재 사이트는 700 이상 굵기가 115회, 중간 굵기(500~600)가 44회다. 화면 대부분이 굵어서 아무것도 강조되지 않는다. → 위계는 **크기·색·여백**으로 만들고, 굵기는 3단(400 본문 / 600 소제목 / 800~900 대제목)만 쓴다.
2. **투어 카드를 3열 균등으로 만들지 말 것.** 매출 대부분이 "와이키키 거북이 스노클링" 한 상품에서 나오는데 지금은 프라이빗·선셋과 같은 크기다. → **주력 1개를 크게, 보조 2개를 작게** 비대칭으로.
3. **그림자를 순수 검정으로 쓰지 말 것.** 바다색 배경 위에 중성 검정 그림자가 얹혀 탁해 보인다. → 배경 색조를 띤 그림자.
4. **라운드를 전부 같게 쓰지 말 것.** 현재 카드·패널·섹션이 모두 32px이라 층위가 안 보인다. → 안쪽 요소는 작게, 바깥 컨테이너는 크게.
5. **가격·인원 숫자에 `tabular-nums`**를 쓴다. 지금은 숫자가 바뀔 때 폭이 흔들린다.
6. **한국어 제목에 `text-wrap: balance`, 본문에 `text-wrap: pretty`, 전역 `word-break: keep-all`.** 지금은 제목 마지막 줄에 한 단어만 떨어진다.
7. **유리(글래스모피즘) 효과는 히어로와 상단 바까지만.** 본문 카드·목록·폼은 불투명 배경. 이유는 두 가지 — 모바일 저사양 기기 스크롤 성능, 그리고 반투명 위 본문 텍스트의 대비 미달.
8. **모든 탭 가능한 요소는 최소 44×44px**, 포커스 표시(`:focus-visible`)를 반드시 넣는다.

## 7. 영어판

같은 레이아웃에 문구만 영어. 실제 영어 문구:

```
헤더:   Home / Reviews / FAQ / Blog · KR · Manage My Booking · Book a Tour
히어로: Waikiki's Best Turtle Snorkeling Tour, Oceanstar
설명:   The undiluted #1 Waikiki Turtle Snorkeling Tour, verified by over
        20,000 customers yearly and 13,000+ reviews!
CTA:    Book Now & Get Best Rate Guarantee
하단:   Undisputed #1 in Hawaii / Best Snorkeling Tour Booking / Book Now
```

**영어판 주의 3가지**

1. **CTA가 한국어의 4배 길다.** 한국어 "바로 예약하기"(7자) vs 영어 "Book Now & Get Best Rate Guarantee"(34자). **375px 버튼 설계를 영어 기준으로 잡아야 한다.**
2. 영어 문구는 한국어 대비 평균 **1.3~1.6배 길다.** 버튼·카드 제목이 2줄까지 깨지지 않게.
3. 줄바꿈 규칙이 다르다. 한국어 `word-break: keep-all` / 영어 `overflow-wrap: break-word`.
4. 통화 기본값 — 한국어 KRW, 영어 USD. 날짜도 `2026년 9월 3일 (수)` vs `Wed, Sep 3, 2026`.

> 참고: 누적 리뷰 수가 한국어판 14,000+, 영어판 13,000+ 로 **서로 다르게 적혀 있다.** 실제 수치로 통일할 것.
